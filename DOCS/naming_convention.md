# Naming convention for nebula
Disse retningslinjene er ment for å sikre konsistens mellom moduler i PCB-design.

# Generelt
### 🐍 Alt bruker snakecase
altså_at_man_skriver_sånn_her

# Netlabels
### 📄 Netlabels skal være i formatet:
[modul(eks: "BNO086")][funksjon(eks: "MISO")][tiltegnet pin på MCU(eks: "30")]

### Eksempel
BNO086_MISO_30

### ⚡ Power
Alle positive powersymbols skal være 3.3V.
